## 四、打包后自检（建议执行）

1. **确认无密钥**：`grep -r "sk-" <解压后的目录>` 应无输出。
2. **确认可安装**：解压到新目录 → `npm install` → `npm run build` 应成功。
3. **确认可建库**：`node scripts/db/build-sqlite.mjs` → 生成 22 张表。
4. **确认可验收**：`MYCARE_DB_PATH=data/mycare-demo.db node scripts/db/verify-step4.mjs` 应 26/26。
5. **确认无绝对路径**：不应出现 `E:\0000项目备份` 这类本机路径。
