# 修复记录 · 登录页白屏导致整体不可进入

- **发现时间**：2026-09-14
- **现象**：打开应用后登录/注册页空白，`#root` 内容为空，任何页面都进不去。
- **严重级别**：P0（应用完全不可用）
- **状态**：已修复并复验

---

## 一、根因（单点，前端渲染期抛错）

`src/pages/LoginPage.jsx` 第 1 行只导入了 `useState`，但组件体内第 180 行使用了 `useEffect`：

```js
// 修复前
import React, { useState } from 'react'   // ← 缺少 useEffect
...
useEffect(() => { listPatients()... }, [])  // ← ReferenceError
```

浏览器实测异常：

```
ReferenceError: useEffect is not defined
    at LoginPage (http://127.0.0.1:3000/src/pages/LoginPage.jsx:193:3)
```

`App.jsx` 在**顶层静态导入**了 `LoginPage`，且 `LoginPage` 位于路由树中，组件渲染时立即抛错；React 因无错误边界而整棵树卸载 → `#root` 为空 → 白屏。因为 Provider 包裹了全部路由（含 `/login`），所以「登录页进不去」和「整体进不去」是同一个原因。

实测证据（无头浏览器抓取）：

| | 修复前 | 修复后 |
|---|---|---|
| 未捕获异常 | 3 条 `useEffect is not defined` | 0 |
| `#root` innerHTML 长度 | **0** | **13043** |
| `document.body.innerText` | 空 | 完整登录页文案 |

## 二、修复内容

`src/pages/LoginPage.jsx`（单文件，2 处）：

1. `import React, { useState, useEffect } from 'react'` —— 补齐缺失的 hook 导入。
2. 顺手消掉同文件内 antd v5 的废弃用法：`<Tabs><TabPane/></Tabs>` → `<Tabs items={[...]} />`，并删除 `const { TabPane } = Tabs`。
   （antd 5.27.4 仍保留 `TabPane` 兼容层所以不是本次白屏的原因，但它会持续以 `error` 级别污染控制台，故一并清理。）

**未改动**：数据链路、`clinicalRules.js`、数据库、患者人设、任何后端逻辑。

### 新增：`scripts/db/verify-ui-routes.mjs`（真实浏览器页面冒烟验收）

- 用本机 Edge 无头模式 + CDP 驱动，**无需下载 Chromium**（`agent-browser` 未安装时的替代路径）。
- 先验收 `/login`，再经 `/api/patients/login` 取患者视图写入 localStorage 模拟登录态，然后**逐路由整页重载**，捕获未捕获异常、error 级控制台输出，并断言 `#root` 非空、未被重定向回登录页。
- 额外静态规则：扫描 `src/` 下所有文件，凡使用了 React API 但未导入即判 FAIL —— 直接拦截本次这类故障。
- 产出：`data/ui-routes-verify-record.json`。

## 五、遗留（非阻塞，不影响使用）

浏览器控制台仍存在**警告级**信息，均不导致故障，已在冒烟脚本中归类为 benign 并记录于 JSON：

1. `Warning: Received \`true\` for a non-boolean attribute` —— 出现在所有登录后页面（登录页无），疑为组件向 DOM 透传自定义布尔属性；纯告警，不影响渲染。
2. `Warning: [antd: Tabs] Tabs.TabPane is deprecated` —— 仅剩 `DataRecordPage` / `BadgePage` / `DoctorPage` 三处仍用 `<TabPane>`，建议后续统一改 `items` API。
3. `Warning: [antd: Card] bodyStyle is deprecated` —— 出现于 `/agents`。

以上三项均建议在后续阶段清理，本次未扩大改动范围。
