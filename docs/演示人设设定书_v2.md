## 第 0 节 · v2 变更摘要与口径红线

### 0.1 v1 → v2 的六处修正

| # | v1 的问题 | v2 的处理 |
|---|---|---|
| 1 | 把"高危预警"当产品术语，与医学危险分层"中危"混用 | 建立**两套独立词表**：医学分层（医生用）与产品预警等级（系统用），互不借用 |
| 2 | "连续异常"没有可执行判定条件 | 给出 **AI 触发规则表**，每条规则含触发条件、级别、动作、用户文案 |
| 3 | "通知家属"默认执行 | 增加**用户授权前提**（`emergencyContact.authorized` + 用户点击确认） |
| 4 | 糖尿病"诊断依据"与"7 天控制情况"写在同一段 | **拆成两节**：既往诊断（长期）+ 本次 7 天趋势（近期），并说明 HbA1c 与 7 天血糖的时间尺度差异 |
| 5 | 7.8 mmol/L 写成"老年标准" | 改为**本病例个体化演示判定阈值**，明确不作普适标准 |
| 6 | "7 天减 1.2 kg 符合每周 0.5–1.0 kg" | 改为**不能等同于脂肪减少**，并说明初期速度不可线性外推；"平台期"改为"短期反弹" |

### 0.2 口径红线（文案禁用清单）

> 以下为答辩现场最容易被追问的点，产品文案与 PPT 一律遵守。

| 禁用表述 | 原因 | 应改为 |
|---|---|---|
| "高危患者""高危预警" | "高危"是医学心血管危险分层术语，本例分层为**中危** | 产品侧："连续异常趋势预警""风险提醒" |
| "重度高血压" | 分级无"重度"一说；本例为 2 级 | "2 级高血压范围" |
| "高血压急症 / 危象" | 需 ≥180/120 mmHg 且伴靶器官损害，本例 162/98 远未达到 | "血压控制恶化" |
| "162/98 确诊为 2 级高血压" | 单次测量不足以诊断分级 | "D7 单次 162/98，落入 2 级区间，作为趋势信号" |
| "老年人血糖统一标准 7.8" | 个体化目标，非普适 | "本病例演示判定阈值" |
| "7 天减 1.2 kg 脂肪" | 体重≠脂肪 | "体重净变化，含水分与测量误差" |
| "进入平台期" | 平台期需连续 2–4 周无变化 | "短期反弹 / 日常波动" |

### 0.3 四层概念分离表（核心）

| 层面 | 术语体系 | 张建国取值 | 由谁给出 |
|---|---|---|---|
| 疾病诊断 | 原发性高血压（分级） | **2 级** | 医生 / 病历 |
| 心血管风险分层 | 低危 / 中危 / 高危 / 很高危 | **中危** | 医生 |
| 控制状态 | 达标 / 未达标 | **未达标**（7 天达标率 42.9%） | AI 分析（确定性算法） |
| 产品预警等级 | 提示 / 关注 / 预警 / 紧急 | **预警** | 系统规则引擎 |

> **关键**：产品预警等级不得使用医学分层词汇；医学分层也不得被产品状态覆盖。两者在界面上分区展示。

### 2.1 张建国 · 高血压

**A. 诊断（既往，长期）**

| 项目 | 内容 |
|---|---|
| 主诊断 | 原发性高血压 |
| 病程 | 确诊 3 年 |
| 用药 | 苯磺酸氨氯地平片 5 mg，每日 1 次，晨服 |
| 合并症 | 超重（BMI 26.0）、中心性肥胖（腰围 92 cm） |
| 靶器官损害 | **无**（眼底、尿微量白蛋白、心电图均未见异常） |
| 其他危险因素 | 男性 ≥55 岁、超重/中心性肥胖（共 2 项） |

**B. 本次血压分级（近期，7 天）**

| 项目 | 内容 |
|---|---|
| 分级依据 | 《中国高血压防治指南（2024 修订版）》诊室血压 |

| 分类 | 收缩压 mmHg | | 舒张压 mmHg |
|---|---|---|---|
| 正常高值 | 120–139 | 和/或 | 80–89 |
| 1 级高血压 | 140–159 | 和/或 | 90–99 |
| **2 级高血压** | **160–179** | 和/或 | **100–109** |
| 3 级高血压 | ≥180 | 和/或 | ≥110 |

- 7 天峰值 **162/98 mmHg**：收缩压落入 160–179 区间 → 该次测量落入 **2 级范围**
- ⚠️ **严谨性说明**：高血压分级应基于非同日多次测量；本例 D7 单次 162/98 作为**趋势恶化信号**使用，**不单独作为诊断依据**
- 危险分层：2 级 + 1–2 个危险因素 → **中危**

**C. 控制目标**

| 项目 | 内容 |
|---|---|
| 目标值 | 诊室血压 **< 140/90 mmHg** |
| 依据 | 65–79 岁老年人先降至 <140/90，能耐受者进一步 <130/80 |
| 7 天达标率 | **42.9%**（3/7 天达标） |

### 2.2 李秀英 · 2 型糖尿病

**A. 诊断（既往，长期）**

| 项目 | 内容 |
|---|---|
| 主诊断 | 2 型糖尿病 |
| 病程 | 确诊 5 年 |
| 诊断标准 | 空腹血糖 ≥7.0 mmol/L，或 OGTT 2h ≥11.1，或 HbA1c ≥6.5%（本例为既往病史诊断） |
| 用药 | 二甲双胍片 0.5 g 每日 2 次；阿卡波糖片 50 mg 每日 3 次（随第一口主食嚼服） |
| 低血糖风险 | **低**（所用药物低血糖风险低，适合老年患者） |
| 并发症筛查 | 尿微量白蛋白正常、眼底未见糖网、足背动脉搏动正常 → **无并发症** |
| 合并症 | 超重（BMI 26.4）、血脂异常（TG 1.9 mmol/L ↑） |

**B. 控制状态（两个时间尺度必须分开）**

| 指标 | 时间尺度 | 本例取值 | 含义 |
|---|---|---|---|
| **HbA1c** | 反映近 **2–3 个月**平均血糖 | **7.8%** | **长期**控制指标，不随 7 天波动 |
| **空腹血糖** | 近 7 天逐日记录 | 7.1–8.5 mmol/L | **近期**趋势指标 |

**C. 控制目标与演示阈值（必须区分）**

| 项目 | 内容 |
|---|---|
| 个体化控制目标 | 空腹 5.0–7.8 mmol/L，HbA1c 7.0%–7.5% |
| **本病例演示判定阈值** | **空腹血糖 7.8 mmol/L** |
| 官方表述 | "本病例根据老年患者个体化控制目标，演示判定阈值采用空腹血糖 7.8 mmol/L。" |
| ⚠️ 限制 | 该阈值仅用于本项目的趋势分析、达标率计算与演示逻辑，**不表述为所有老年糖尿病患者统一适用的医学标准** |
| 7 天达标率 | **57.1%**（4/7 天 ≤7.8） |

### 2.3 王建军 · 肥胖症

**A. 诊断**

| 项目 | 内容 |
|---|---|
| 主诊断 | 肥胖症（一级） |
| BMI 分级依据 | 《肥胖症诊疗指南（2024 年版）》中国标准 |

| BMI (kg/m²) | 判定 |
|---|---|
| < 18.5 | 低体重 |
| 18.5–23.9 | 正常 |
| 24.0–27.9 | 超重 |
| **28.0–32.4** | **肥胖（一级）** |
| 32.5–37.4 | 肥胖（二级） |
| ≥ 37.5 | 肥胖（三级） |

- 中心性肥胖：腰围 104 cm（男性 ≥90 cm）
- 合并代谢综合征（CDS 标准，≥3 项）：
  1. 超重/肥胖：BMI 31.1 ✅
  2. 高血糖：空腹血糖 6.3 mmol/L（≥6.1，空腹血糖受损 IFG）✅
  3. 血脂紊乱：TG 2.4 mmol/L ↑、HDL-C 0.92 mmol/L ↓ ✅
  （血压 136/84 mmHg 未达 140/90，不计入）
- 用药：**暂未启动药物减重**，首选生活方式干预

**B. 减重目标与体重解读口径**

| 项目 | 内容 |
|---|---|
| 医学目标 | 3–6 个月减重 **5%–10%**（本例即 **4.6–9.2 kg**） |
| 推荐速度 | 每周 0.5–1.0 kg（中长期匀速） |
| 本例 7 天净变化 | **−1.2 kg** |
| ⚠️ 正确解读 | 1.2 kg 包含**水分、糖原储备、进食与测量时间差异**，**不能等同于脂肪减少 1.2 kg**；减重初期下降速度通常快于后期，**不宜线性外推** |
| ⚠️ 关于 D5→D6 回升 0.6 kg | **不称"平台期"**。平台期需连续 2–4 周无变化；7 天内的单日回升属**短期反弹 / 日常波动** |
| 更可靠指标 | 建议同时看**腰围**与**体脂率**，而非单一体重 |

## 表 4 · AI 触发规则表

> 规则引擎为**确定性算法**，不依赖大模型判断；大模型只负责把结果转成自然语言。

### 4.1 血压规则（对应张建国）

| 规则 ID | 名称 | 触发条件 | 级别 | 系统动作 | 用户可见文案 |
|---|---|---|---|---|---|
| R-BP-1 | 单次超标提示 | 单日 SBP ≥140 或 DBP ≥90，且前一日未超标 | 提示 | 记录，不生成工单 | "今日血压略高于目标值，请继续监测。" |
| **R-BP-2** | **连续异常趋势预警** | **连续 ≥3 天 SBP ≥140 且 7 天 SBP 涨幅 ≥10 mmHg** | **预警** | `raise_alert` 生成风险工单 + 生成低盐处方 + `schedule_reminder` 复诊提醒 | "近 7 天血压持续升高，已连续 4 天超过 140/90 的目标值，建议近期复诊评估。" |
| R-BP-3 | 严重超标强预警 | 单日 SBP ≥180 或 DBP ≥110，或伴胸痛/头晕/视物模糊 | 紧急 | 强提醒 + 立即就医建议 + 可触发通知紧急联系人 | "血压显著升高，建议立即就医。" |

|---|---|---|---|---|---|
| R-WT-1 | 记录达成 | 当日有体重/运动记录 | 正向 | 积分 +10 | "今日已完成记录。" |
| **R-WT-2** | **减重进展反馈** | **7 天净减 ≥0.5 kg** | **正向** | 生成阶段小结 | "这 7 天体重下降了 1.2 kg（含水分与测量波动），继续保持。" |
| R-WT-3 | 短期反弹提醒 | 单日回升 ≥0.5 kg | 关注（柔性） | 解读波动，不报警 | "体重比昨天回升 0.6 kg，属日常波动，不必焦虑。" |
| R-WT-4 | 运动达标激励 | 单日步数 ≥8000 **或** 周运动 ≥150 min | 正向 | 发勋章 / 显示进度 | "本周运动 200 分钟，已达推荐量。" |
| R-WT-5 | 勋章解锁 | 命中勋章规则 | 正向 | 授予勋章 + 积分 | "解锁「坚持不懈」勋章。" |

**本例命中：R-WT-1 + R-WT-2 + R-WT-3 + R-WT-4（运动部分）+ R-WT-5**

### 4.4 三级预警等级定义（产品侧）

| 等级 | 色值（中国习惯） | 含义 | 是否生成工单 |
|---|---|---|---|
| 提示 info | 灰 / 蓝 | 单次轻微异常，继续观察 | 否 |
| 关注 watch | 黄 | 出现波动或反复，需留意 | 否 |
| 预警 alert | 橙 | 连续异常趋势，建议就医/调整 | **是** |
| 紧急 emergency | 红 | 严重超标或急性症状 | 是 + 强提醒 |

> "您近 7 天的收缩压从 132 上升到 162 mmHg，最近 4 天都超过了 140/90 的控制目标。这个持续上升的趋势值得重视，建议近期到心内科复诊评估用药。您平时爱吃腌菜、口味偏咸，先从每天食盐减到 5 g 以下做起。"

### 5.2 剧本 B｜李秀英 —— 解决问题（辅助管理）

| 步骤 | 触发者 | 画面 / 内容 |
|---|---|---|
| ① 用户行为 | 用户 | 打开血糖趋势页 → 录入今日空腹血糖 **8.3** |
| ② 系统发现 | steward | 计算 7 天达标率与极差 |
| ③ AI 分析 | vitals | "近 7 天有 3 天未达标，达标率 57.1%，且呈上升趋势；最高 8.5（D6），最低 7.1，波动 1.4。" |
| ④ AI 找原因 | planner | **读取生活画像** `diet: 主食以面食为主，蔬菜偏少，进餐速度快` |
| ⑤ AI 方案（个性化） | planner | 依据画像给出**可执行**建议（见下） |

**情感陪伴台词**

> "连续几天没达标确实容易让人泄气。不过您这 7 天有 4 天是达标的，说明方法是有效的，我们先把其中一条习惯固定下来。"

**要点**：重点不在"AI 知道糖尿病"，而在 **AI 能否基于她的真实习惯给出可执行建议**。
